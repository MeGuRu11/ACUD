# Дизайн установщика АСУД на Inno Setup

## Цель

Создать полностью русскоязычный установщик Windows для АСУД, который визуально соответствует фирменному варианту B: тёмная бренд-панель, крупная иконка приложения, спокойная бирюзово-графитовая палитра и понятный сценарий установки.

## Состав решения

Установщик создаётся Inno Setup 6 из готового `dist/ASUD.exe`. В пакет входят только исполняемый файл приложения и необходимые ресурсы установщика. Локальные рабочие данные (`asud.sqlite3`, `config.json`, `users.json`, `audit.log`, `backups/`, `last_data.csv`) не включаются.

Результат сборки:

- `installer/ASUD.iss` — основной сценарий Inno Setup;
- `installer/assets/wizard-large.bmp` — фирменная левая панель мастера;
- `installer/assets/wizard-small.bmp` — изображение для внутренних страниц;
- `build_installer.bat` — русскоязычный сценарий полной сборки EXE и установщика;
- `release/ASUD-Setup-1.0.0.exe` — готовый установщик.

## Сценарий установки

1. Приветственный экран сообщает назначение АСУД и подчёркивает, что установка будет чистой.
2. Приложение устанавливается для текущего пользователя в `{localappdata}\Programs\ASUD`.
3. Создаётся ярлык в меню «Пуск».
4. Создание ярлыка на рабочем столе доступно как включённая по умолчанию задача.
5. После установки пользователь может сразу запустить АСУД.
6. При первом запуске на новом устройстве приложение создаёт `%LOCALAPPDATA%\ASUD` и предлагает создать первого администратора.

Установка не требует прав администратора. Повторная установка обновляет программный файл, не затрагивая базу данных пользователя.

## Визуальный стиль

- современный мастер `WizardStyle=modern`;
- основной цвет: `#16877C`;
- тёмный фирменный фон: `#102D36`;
- белая иконка со щитом/крестом на бренд-панели;
- русские заголовки и пояснения;
- название продукта: `АСУД`;
- полное название: `Автоматизированная система учёта диссертаций`;
- издатель: `ВМедА им. С.М. Кирова`.

Стандартные элементы Windows сохраняются, чтобы мастер был предсказуемым и доступным. Фирменность обеспечивается изображениями мастера, иконкой, текстами и цветами.

## Деинсталляция и данные

Деинсталлятор удаляет программу и созданные ярлыки. Рабочие данные в `%LOCALAPPDATA%\ASUD` сохраняются по умолчанию, поскольку их автоматическое удаление может привести к потере реестра диссертаций и учётных записей.

Установщик не переносит данные из каталога сборки и не копирует существующую локальную базу разработчика.

## Сборка

`build_installer.bat`:

1. проверяет наличие Python и Inno Setup 6;
2. запускает `build_exe.bat --no-pause`;
3. проверяет наличие `dist\ASUD.exe`;
4. проверяет, что runtime-файлы не входят в список источников установщика;
5. запускает `ISCC.exe installer\ASUD.iss`;
6. проверяет `release\ASUD-Setup-1.0.0.exe`;
7. выводит русскоязычный результат и путь к установщику.

Если Inno Setup не найден, сценарий выводит понятную инструкцию по установке через `winget install JRSoftware.InnoSetup`.

## Проверка

Автоматические тесты проверяют:

- русскую локализацию сценария;
- современный стиль и фирменные изображения;
- установку в профиль текущего пользователя;
- наличие ярлыков и деинсталлятора;
- отсутствие runtime-данных в `[Files]`;
- корректную связь `build_installer.bat` с `build_exe.bat` и `ISCC.exe`;
- игнорирование `release/` и сгенерированных BMP Git-репозиторием.

Ручная проверка выполняется сборкой установщика и запуском его в режиме проверки Inno Setup. После установки запускается АСУД и подтверждается экран создания первого администратора при отсутствии `%LOCALAPPDATA%\ASUD`.
